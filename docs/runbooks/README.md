# Runbooks

Step-by-step fixes for things that go wrong. Each runbook has: symptoms, cause,
fix (copy-pasteable commands), how to verify, and how to prevent a repeat.
Write or update one after every incident.

| Runbook | Status |

| A simulator day was missed before `dbt snapshot` | to write |
